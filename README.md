# NATIVO V5 — EDICIÓN MÓVIL

Esta carpeta contiene la **web COMPLETA** para publicar en GitHub Pages. No necesitas mezclar archivos V4 ni editar el código.

## Archivos que debes subir a la raíz del repositorio

- `index.html` — página web
- `styles.css` — estilos base
- `script.js` — interacciones base
- `mobile.css` — rediseño y animaciones móviles
- `mobile.js` — navegación inferior y efectos táctiles
- `.nojekyll` — GitHub Pages
- `README.md` — estas instrucciones
- `assets/` — todas las imágenes

## Cómo instalar

1. Descomprime el ZIP.
2. Abre tu repositorio de GitHub desde una computadora.
3. Sube **todo lo que está dentro de la carpeta** (no la carpeta contenedora).
4. Sobrescribe los archivos existentes. No olvides subir `mobile.css` y `mobile.js`.
5. Comprueba que `index.html` esté en la raíz y `assets/` sea una carpeta.
6. GitHub Settings > Pages > Deploy from a branch > `main` > `/(root)`.
7. Prueba con el navegador en modo incógnito y actualiza si la versión antigua permanece almacenada.

## Qué mejora V5 en celular

- Imagen principal completa con `object-fit: contain` y sin recorte.
- Portada dividida: imagen arriba, textos y botones debajo.
- Barra inferior de navegación (Inicio, Creatina, Historias y Comunidad).
- Progreso de lectura arriba.
- Gestos y desplazamiento natural, carrusel con snap y tarjetas en foco.
- Entradas de texto, imágenes y botones con animaciones fluidas.
- Menú con entrada escalonada y botones táctiles grandes.
- Respeto a la preferencia de accesibilidad `prefers-reduced-motion`.

## Importante

Es un prototipo: no procesa pagos ni registra correos. Las etiquetas e imágenes del producto son ilustrativas y no acreditan por sí mismas pureza ni análisis del lote. No uses fotografías del atleta comercialmente sin autorización.
